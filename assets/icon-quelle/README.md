# Icon-Quellen

Vektorvorlagen für das App-Icon von Inspacktor (Raster 108 × 108 wie bei adaptiven
Android-Icons; alles Wichtige liegt im sicheren Kreis mit Radius 33 um die Mitte).

| Datei | Wird zu |
|---|---|
| `vordergrund.svg` | `assets/images/android-icon-foreground.png` (1024 px) |
| `hintergrund.svg` | `assets/images/android-icon-background.png` (1024 px) |
| `monochrom.svg` | `assets/images/android-icon-monochrome.png` (1024 px, Themen-Icons ab Android 13) |
| `icon.svg` | `assets/images/icon.png` (1024 px) und `favicon.png` (48 px) |

Farben: Dunkelgrün `#1F2A24`, Ocker `#E0A458` / `#B9772E`, Creme `#F6F3EC` – wie in der App.
Zum Umwandeln eignet sich jedes Programm, das SVG als PNG exportiert (z. B. Inkscape).
